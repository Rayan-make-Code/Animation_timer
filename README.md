# MIYP Timer

Портативное Windows-приложение для практики набросков: подключает вашу папку с изображениями и проводит интервальные сессии (работа/отдых, группы повторов) с полноэкранным показом. Весь интерфейс умещается на одном экране.

## Возможности

- Пресеты показаны часами с суммой времени; циферблат выбранного пресета отображает работу, отдых и подготовку.
- Категории выбираются тегами (по умолчанию все выключены), под ними блок «Старт» с полосой цикла.
- Редактор пресета: этапы с повторами, работой и отдыхом.
- Подвал: шестерёнка с «Обновить», «Переименовать», «Бэкап», «Импорт» и путь к папке библиотеки.
- Сессия на весь экран: полоса прогресса, шторка с таймером, лайк, дизлайк (файл уходит в Корзину), сигнал в конце интервала.
- Клавиши сессии: Пробел, ←, →, L, D, Esc.

## Разработка

Стек: Electron + React + TypeScript, SQLite через встроенный `node:sqlite` (Node ≥ 22.13).

```bash
npm install
npm test            # Vitest: вся логика в src/core
npm run typecheck
npm start           # собрать и запустить (данные в ./data)
npm run e2e         # Playwright + Electron (на Linux: npm run e2e:linux)
npm run package:win # портативный ZIP release/MIYP-Timer-<версия>-win32-x64.zip
```

Иконка exe лежит в `build/icon.ico`. На Linux для её вшивания нужен `wine`; без него сборка проходит с предупреждением и без иконки.

Структура: `src/core` — логика без Electron (база, библиотека, переименование, выбор, таймер, бэкап), `electron/` — окно и IPC, `src/renderer` — интерфейс.
