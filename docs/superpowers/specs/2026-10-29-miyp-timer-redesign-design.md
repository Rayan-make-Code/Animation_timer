# MIYP Timer: редизайн интерфейса — спецификация

Основа: [спецификация 0.1](2026-10-28-sketch-timer-design.md). Всё, что здесь не сказано, остаётся как было (данные, переименование, выбор изображений, таймер, бэкап). Интерфейс согласован в макете «MIYP Timer — редизайн» (доски «Главный экран», «Сессия», «Варианты шрифта», выбран вариант E).

## 1. Название и иконка

- Продукт называется **MIYP Timer**: `productName`, заголовок окна, шапка, `MIYP Timer.exe`, архив `MIYP-Timer-<версия>-win32-x64.zip`, `version.txt`, README и ИНСТРУКЦИЯ. Версия 0.2.0, `name` в package.json — `miyp-timer`.
- Иконка: чёрная фигурка (`build/icon.ico` для exe, `src/renderer/assets/icon.png` для шапки).
- Совместимость с 0.1 не ломаем: файл базы `data/sketch-timer.db`, протокол `sketch-image://` и формат бэкапа `sketch-timer-backup` остаются прежними. Имя файла бэкапа по умолчанию — `miyp-timer-<дата>.sketchbackup.json`.

## 2. Окно

- Один экран без вкладок. Ширина окна фиксирована: **406 px** (ряд из шести пресетов: 6 × 58 px, промежутки 6 px, поля 14 px). Высота по умолчанию 760 px, минимум 560 px; при нехватке высоты прокручивается содержимое, шапка и подвал на месте.
- Рамка своя (как в 0.1): иконка, «MIYP Timer», кнопки «Свернуть» и «Закрыть».
- Сессия идёт в полноэкранном режиме; после выхода окно возвращается к 406 px.
- Палитра прежняя (#141519 фон, #1a1b20 шапка, #2a2b32 линии, #7cc4ff работа, #7fd39b отдых, #b9bbc6 подготовка). Кнопки с радиусом 6–8 px, овальных нет. Шрифт интерфейса: `Segoe UI Variable Text`, `Segoe UI`, системный, начертание 300. Цифры таймеров: **Exo 2, 200** (встраивается в сборку через `@fontsource/exo-2`, сеть не нужна).
- У каждой кнопки-иконки всплывающая подсказка (`data-tip`) и `aria-label`.

## 3. Главный экран (сверху вниз)

1. **Пресеты.** Горизонтальный ряд: у каждого пресета иконка часов 44 px без засечек и под ней сумма сессии (`35 мин`, `1 ч 20 мин`). Выбранный обведён. В конце кнопка «новый» (пунктирный квадрат с плюсом). При 7+ пресетах ряд прокручивается по горизонтали.
2. **Циферблат выбранного пресета** (236 px). 60 засечек по кругу, засечка i покрывает отрезок `[i, i+1) · общее / 60` от начала сессии. Цвет засечки — фаза в середине отрезка (подготовка / работа / отдых). Если в отрезке начинается отдых, засечка длиннее и выступает наружу, поэтому видно реальное число и положение отдыхов. В центре: общее время (`37m 15s`), строка `00:05 | ГОТОВ` и первый шаг (`1. Приготовьтесь`). Под циферблатом следующий шаг: `» 2. Быстрые наброски — 1:00`.
3. **Описание** пресета: `Название — описание`.
4. **Категории** в виде тегов: по одному на каждую папку дерева (включая корневую, если в ней лежат изображения). Без `#`, без чисел, без тега «Лайки». По умолчанию все выключены, клик включает или выключает. Подкатегории другого цвета (сиреневые), категории верхнего уровня голубые. Выбор категории включает её подкатегории (как в 0.1). Выбор запоминается.
5. **Старт.** Слева узкая вертикальная полоса цикла (заполнена на просмотренную долю). Текст: `37m 15s · 38 рис.` и `цикл: осталось 141 из 268`. Справа иконки «Редактировать пресет», «Удалить пресет» (с подтверждением) и кнопка **«Старт»**. «Старт» неактивна без выбранной категории или без библиотеки, подсказка объясняет почему.
6. **Подвал.** Шестерёнка открывает или скрывает панель библиотеки над подвалом: «Обновить», «Переименовать», «Бэкап», «Импорт». Рядом путь к папке библиотеки; клик по пути открывает выбор новой папки, диалог стартует **с текущей папки**. Без библиотеки вместо пути «Папка не выбрана».

Последний выбранный пресет и выбранные категории сохраняются в `settings`.

### Редактор пресета

Открывается кнопкой «Редактировать» или «новый» на месте циферблата. Компоненты выезжают по очереди (анимация `slideIn` 0,36 с, задержка 0,04 с + 0,08 с на каждый следующий блок; при `prefers-reduced-motion` без анимации).

- Поля: название, описание.
- Этапы списком: `повторы ×`, название, работа `м:сс`, отдых `м:сс`. Первая строка «Приготовьтесь» — обычный этап 1× без отдыха (правило из 0.1).
- Панель над списком: «Добавить этап», «Дублировать», «Переставить» (вверх), «Удалить» для выбранной строки. Кнопку «Сгруппировать в повтор» из макета не делаем: повторы уже задаются числом в строке.
- «Отмена» и «Сохранить». Ошибки проверки показываются под списком (`validatePreset`).

### Первый запуск

- Если пресетов нет, создаются и сразу **сохраняются** три стандартных: «Разминка» (5 с подготовка, 35 × 1:00 / 0:15, 2 × 3:00 / 0:15, 1 × 5:00 / 0:15), «Жесты 20» (30 × 0:30 / 0:10), «Длинная» (10 × 2:00 / 0:20, 3 × 15:00 / 1:00).
- Пока первый запуск не завершён, клик по пресету сразу открывает его редактор, а панель библиотеки открыта. После первого старта сессии флаг `firstRunDone` записывается в `settings`, дальше панель по умолчанию скрыта, а клик по пресету показывает циферблат.

## 4. Экран сессии

- Изображение на весь экран (`object-fit: contain`).
- Вверху по всей ширине голубая полоса прогресса 3 px: просмотрено / всего рабочих интервалов.
- По центру сверху неяркая «шторка»: цветная точка фазы (работа голубая, отдых зелёная), время `0:42` (Exo 2 200), счётчик `12/38`. Название пресета не показывается.
- Справа снизу компактная панель кнопок 28 px: «Назад», «Пауза/Продолжить», «Вперёд», «Лайк» (зелёное сердце, повторное нажатие снимает), «Дизлайк» (красная урна), «Выйти» (иконка EXIT с человечком и дверью). Клавиши как в 0.1: Пробел, ←, →, L, D, Esc.
- **Звук**: в конце каждого интервала (работы, отдыха, подготовки), когда шаг закончился по времени, звучит короткий мягкий сигнал (WebAudio, синус ~880 Гц, 150 мс, плавное затухание). При ручной навигации сигнала нет.
- «Выйти» и Esc сразу возвращают на главный экран, засчитанные просмотры сохраняются. По окончании расписания тоже возврат на главный экран со строкой итога в блоке «Старт» (`Сессия завершена: 38 рис.`).

### Дизлайк

- Дизлайк **переносит файл в Корзину Windows** (`shell.trashItem`), запись изображения получает `missing = 1` и в выборе и подсчётах больше не участвует. Сессия сразу переходит к следующему изображению. Подтверждения нет, файл можно восстановить из Корзины; после «Обновить» восстановленный файл вернётся в ротацию.
- Если перенос не удался (файл занят, нет прав), файл остаётся на месте, показывается короткое сообщение, сессия продолжается.
- Дизлайки, поставленные в 0.1 (`rating = -1`), по-прежнему исключены из выбора.

## 5. Новое в ядре (`src/core`)

- `dialTicks(steps, n = 60)` → `{ deg, phase, long }[]`: расчёт засечек для циферблата (чистая функция).
- `formatTotal(sec)` → `37 мин` / `1 ч 20 мин`; `formatClock(sec)` → `37m 15s`.
- `cycleStatus(db, categoryIds)` → `{ remaining, total }` по тем же правилам, что первый круг `buildQueue`.
- `trashImage(db, root, imageId, trash)`: вызывает переданную функцию переноса в корзину по абсолютному пути внутри библиотеки, затем ставит `missing = 1`. Функция переноса передаётся параметром, чтобы тесты не трогали настоящую корзину.
- `seedDefaultPresets(db)`: создаёт три пресета, если таблица пустая; повторный вызов ничего не делает.
- `getSetting / setSetting` для `selectedPreset`, `selectedCategories`, `firstRunDone`.
- Редактор пресета: чистые операции над списком этапов (`addGroup`, `duplicateGroup`, `moveGroupUp`, `removeGroup`).
- `SessionMachine.tick` сообщает, сколько шагов закончилось по времени (для звука).

## 6. Удаляется

Экраны и вкладки «Библиотека», «Оценённые», «Пресеты», «Настройка сессии» и их компоненты: всё переносится на главный экран. Список лайков и дизлайков как отдельный экран больше не показывается (лайки по-прежнему повышают вес выбора).

## 7. Тесты

- Vitest (TDD): `dialTicks`, форматирование времени, `cycleStatus`, `trashImage` (успех, ошибка переноса, путь вне библиотеки), `seedDefaultPresets` (идемпотентность), настройки, операции редактора, сигнал окончания шага в `SessionMachine`.
- Playwright (Electron): подключение библиотеки, теги категорий, запуск сессии, лайк, дизлайк (перенос в тестовую «корзину» через `SKETCH_FAKE_TRASH` только в режиме разработки), выход, первый запуск со стандартными пресетами, создание пресета в редакторе.
- CI на Windows как в 0.1; архив собирается в CI.

## 8. Вне объёма

Переключение циферблата на электронные часы, циферблат на экране сессии, отдельный экран лайков, настройка звука.
