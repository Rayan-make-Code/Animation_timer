# MIYP Timer — инструкция

Распакуйте архив в любую папку, куда можно писать (например, «Документы»), и запустите `MIYP Timer.exe`. Установка не нужна. Рядом с программой создаётся папка `data` с базой `sketch-timer.db`: в ней оценки, история просмотров и пресеты. Чтобы перенести программу, копируйте всю папку вместе с `data`.

## Главный экран
Всё находится на одном экране, сверху вниз:
1. **Пресеты.** Ряд часов, под каждыми сумма времени сессии (`35 мин`, `1 ч 20 мин`). Выбранный пресет обведён; «новый» создаёт пресет.
2. **Циферблат.** 60 засечек показывают всю сессию по кругу: подготовка, работа и отдых разными цветами, отдых выступает наружу. В центре общее время и первый шаг, под ним следующий.
3. **Описание** пресета.
4. **Категории.** Теги по папкам библиотеки, по умолчанию все выключены; клик включает или выключает. Подкатегории другого цвета. Выбор категории включает её подкатегории. Выбор запоминается.
5. **Старт.** Вертикальная полоса показывает, какая часть цикла просмотрена; рядом число рисунков и «цикл: осталось 141 из 268». Иконки справа редактируют и удаляют пресет (удаление с подтверждением). «Старт» неактивна без библиотеки или без выбранной категории; подсказка объяснит причину.
6. **Подвал.** Шестерёнка открывает панель: «Обновить», «Переименовать», «Бэкап», «Импорт». Рядом путь к папке библиотеки; клик по нему открывает выбор другой папки.

## Первый запуск
1. Нажмите на путь в подвале («Папка не выбрана») и выберите папку с изображениями. Папки первого уровня становятся категориями, вложенные — подкатегориями.
2. Приложение проиндексирует изображения (jpg, jpeg, png, webp, bmp, avif; GIF не используется) и переименует новые файлы в формат `Папка_img_01`. Файлы никогда не перезаписываются.
3. Новые папки и файлы подхватываются при запуске и по кнопке «Обновить» (шестерёнка в подвале). Кнопка «Переименовать» запускает переименование вручную.
4. Сразу доступны три готовых пресета: «Разминка», «Жесты 20» и «Длинная». Пока вы не начали первую сессию, клик по пресету открывает его редактор.

## Редактор пресета
Открывается кнопкой «Редактировать» или «новый» на месте циферблата. Укажите название и описание, затем этапы: число повторов, название, время работы и отдыха (`м:сс`). Кнопки над списком: «Добавить этап», «Дублировать», «Переставить» (вверх), «Удалить». Ошибки показываются под списком; «Сохранить» и «Отмена» внизу.

Если первый этап состоит из одного повтора без отдыха (например, «Приготовьтесь», 5 с), он считается подготовкой: показывает первое изображение и не засчитывается.

## Сессия
Выберите пресет и хотя бы одну категорию, нажмите «Старт». Изображение открывается на весь экран. Вверху полоса прогресса и шторка с цветной точкой фазы, временем и счётчиком `12/38`. Справа снизу кнопки: назад, пауза, вперёд, лайк, дизлайк и выход. В конце каждого интервала звучит короткий сигнал (при ручном переключении его нет).

| Клавиша | Действие |
|---|---|
| Пробел | пауза / продолжить |
| → / ← | следующее / предыдущее изображение |
| L | лайк (повторное нажатие снимает) |
| D | дизлайк |
| Esc | выйти на главный экран |

Изображение считается просмотренным, когда закончился его рабочий интервал. Пропуск стрелкой вперёд просмотр не засчитывает. Выход сохраняет уже засчитанные просмотры; по окончании расписания программа сама возвращается на главный экран. Лайкнутые изображения выпадают в 3 раза чаще.

**Дизлайк переносит файл в Корзину Windows** и сразу показывает следующее изображение. Подтверждения нет; файл можно восстановить из Корзины, после «Обновить» он вернётся в ротацию. Если перенести файл не удалось, он остаётся на месте, а сессия продолжается.

## Резервная копия
«Бэкап» (в панели шестерёнки) сохраняет оценки и пресеты в файл `miyp-timer-<дата>.sketchbackup.json`. «Импорт» переносит их на другой компьютер: изображения сопоставляются по пути в библиотеке, затем по имени и размеру файла. Сами изображения в копию не входят. Копии из версии 0.1 тоже подходят.

## Если программа не запускается
Сообщение «Нет доступа на запись в папку данных» значит, что программа лежит в защищённой папке (например, `Program Files`). Переместите её в «Документы».
