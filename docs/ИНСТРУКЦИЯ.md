# Sketch Timer — инструкция

Распакуйте архив в любую папку, куда можно писать (например, «Документы»), и запустите `Sketch Timer.exe`. Установка не нужна. Рядом с программой создаётся папка `data` с базой `sketch-timer.db`: в ней оценки, история просмотров и пресеты. Чтобы перенести программу, копируйте всю папку вместе с `data`.

## Первый запуск
1. Вкладка «Библиотека» → «Выбрать папку». Папки первого уровня становятся категориями, вложенные — подкатегориями.
2. Приложение проиндексирует изображения (jpg, jpeg, png, webp, bmp, avif; GIF не используется) и переименует новые файлы в формат `Папка_img_01`. Файлы никогда не перезаписываются.
3. Новые папки и файлы подхватываются при запуске и по кнопке «Обновить». Кнопка «Переименовать» запускает переименование вручную.

## Пресеты таймера
Вкладка «Пресеты»: этап = число повторов × (упражнение + отдых). Если первый этап состоит из одного повтора без отдыха (например, «Приготовьтесь», 5 с), он считается подготовкой: показывает первое изображение и не засчитывается.

## Сессия
Вкладка «Сессия»: отметьте категории, выберите пресет, «Начать».

| Клавиша | Действие |
|---|---|
| Пробел | пауза / продолжить |
| → / ← | следующее / предыдущее изображение |
| L / D | лайк / дизлайк (повторное нажатие снимает оценку) |
| Esc | завершить сессию (с подтверждением) |

Изображение считается просмотренным, когда закончился его рабочий интервал. Пропуск стрелкой вперёд просмотр не засчитывает. Лайкнутые изображения выпадают в 3 раза чаще, дизлайкнутые не показываются.

## Резервная копия
«Резервная копия» сохраняет оценки и пресеты в файл `.sketchbackup.json`. «Импорт оценок и пресетов» переносит их на другой компьютер: изображения сопоставляются по пути в библиотеке, затем по имени и размеру файла. Сами изображения в копию не входят.

## Если программа не запускается
Сообщение «Нет доступа на запись в папку данных» значит, что программа лежит в защищённой папке (например, `Program Files`). Переместите её в «Документы».
